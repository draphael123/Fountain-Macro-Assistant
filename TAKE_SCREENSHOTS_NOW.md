# Take Screenshots Now - Quick Guide

## 🎯 What You Need

Take 4 screenshots of your extension in action. The website is already set up to display them automatically!

## 📸 Required Screenshots

1. **usage-1-popup.png** - Extension popup with macros
2. **usage-2-creating-macro.png** - Add Macro modal
3. **usage-3-text-expansion.png** - Text expanding in a text field
4. **usage-4-settings.png** - Settings/Options page

## ⚡ Quick Steps

### 1. Extension Popup
- Click extension icon in Chrome toolbar
- Show popup with 3-5 macros visible
- Take screenshot (Windows: `Win+Shift+S`, Mac: `Cmd+Shift+4`)
- Save as `usage-1-popup.png`

### 2. Creating Macro
- Click "+ Add Macro" in popup
- Fill in example: `/email` → `your.email@example.com`
- Take screenshot of modal
- Save as `usage-2-creating-macro.png`

### 3. Text Expansion
- Go to Google Docs or Gmail
- Type `/email ` (with space)
- Show it expanding
- Take screenshot
- Save as `usage-3-text-expansion.png`

### 4. Settings Page
- Right-click extension → "Options"
- Show settings page with export buttons
- Take screenshot
- Save as `usage-4-settings.png`

## 📁 Save Location

Place all 4 files in:
```
vercel-landing/screenshots/
```

## ✅ That's It!

Once you add the files, they'll automatically appear on the website. No code changes needed!

## 🛠️ Helper Tool

Open `vercel-landing/screenshot-helper.html` in your browser for an interactive guide with step-by-step instructions!
