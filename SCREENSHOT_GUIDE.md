# Screenshot Guide for Chrome Web Store Submission

## Overview

You need at least **1 screenshot** (up to 5 allowed) for your Chrome Web Store listing. Screenshots should be:
- **Minimum size**: 1280x800 or 640x400 pixels
- **Recommended**: 1280x800 pixels
- **Format**: PNG or JPEG
- **Content**: Show the extension popup, options page, or demonstrate usage

## Required Screenshots

### Screenshot 1: Extension Popup (REQUIRED)
**Priority**: ⭐⭐⭐ High - This is the main screenshot

**What to show:**
- Extension popup with several example macros
- Search functionality visible
- Folder organization (if you have folders)
- "+ Add Macro" button visible
- Clean, organized appearance

**Steps to create:**
1. Open Chrome and load your extension (chrome://extensions → Developer mode → Load unpacked)
2. Click the extension icon to open the popup
3. Create 3-5 example macros:
   - `/email` → `your.email@example.com`
   - `/phone` → `(555) 123-4567`
   - `/sig` → `Best regards, Your Name`
   - `/date` → `Today is {date}`
4. Make sure the popup looks full and organized
5. Take screenshot:
   - **Windows**: Press `Windows + Shift + S` (Snipping Tool) or use `Alt + Print Screen`
   - **Mac**: Press `Cmd + Shift + 4`, then drag to select area
   - **Tip**: Make the popup window larger if needed, or use browser zoom to make it more visible

**Editing tips:**
- Crop to show just the popup (remove browser chrome)
- Ensure text is readable
- Add a subtle border or shadow if needed
- Resize to exactly 1280x800 if possible

---

### Screenshot 2: Adding/Editing Macro (RECOMMENDED)
**Priority**: ⭐⭐ Medium

**What to show:**
- The "Add Macro" or "Edit Macro" modal
- Form fields filled with example data
- Show advanced features like aliases or conditional expansions
- Clean, professional appearance

**Steps to create:**
1. Open extension popup
2. Click "+ Add Macro" button
3. Fill in example data:
   - Shortcut: `/email`
   - Expansion: `your.email@example.com`
   - Optionally show alias or conditional expansion
4. Take screenshot of the modal
5. Crop and resize to 1280x800

---

### Screenshot 3: Settings/Options Page (OPTIONAL)
**Priority**: ⭐ Low

**What to show:**
- Options page with export/import features
- Settings visible
- Clean interface

**Steps to create:**
1. Right-click extension icon → Options (or go to chrome://extensions → Details → Extension options)
2. Show the options page with export/import buttons
3. Take screenshot
4. Crop and resize to 1280x800

---

### Screenshot 4: Text Expansion in Action (OPTIONAL)
**Priority**: ⭐ Low

**What to show:**
- Before: Text field with shortcut typed (e.g., `/email`)
- After: Text expanded (e.g., `your.email@example.com`)
- Or show a side-by-side comparison

**Steps to create:**
1. Open a text field (Google Docs, Gmail compose, etc.)
2. Type a shortcut (e.g., `/email `)
3. Show it expanded
4. Take screenshot
5. Add annotations if helpful (arrows, labels)

---

## Tools for Creating Screenshots

### Built-in Tools
- **Windows**: Snipping Tool (`Windows + Shift + S`) or Print Screen
- **Mac**: Screenshot (`Cmd + Shift + 4`) or Grab app
- **Linux**: `gnome-screenshot` or `scrot`

### Online Tools
- **Canva**: Free design tool, good for adding text/annotations
- **Photopea**: Free online Photoshop alternative
- **Remove.bg**: Remove backgrounds if needed

### Desktop Tools
- **Greenshot** (Windows): Free screenshot tool
- **Lightshot** (Windows/Mac): Quick screenshot tool
- **Snagit** (Paid): Professional screenshot tool

## Editing Tips

1. **Crop carefully**: Remove unnecessary browser chrome, focus on extension UI
2. **Resize properly**: Use image editor to resize to exactly 1280x800
3. **Add annotations** (optional): Use arrows or labels to highlight features
4. **Keep it clean**: Remove personal information, use example data
5. **Consistent style**: If taking multiple screenshots, keep them visually consistent

## Quick Start: Minimum Required

If you're in a hurry, you only need **Screenshot 1** (Extension Popup). Make it count:

1. Create 4-5 example macros
2. Open popup
3. Take screenshot
4. Crop to show just popup
5. Resize to 1280x800
6. Save as PNG

That's it! You can add more screenshots later when updating your listing.

## Where to Save Screenshots

Create a folder called `screenshots` in your project root and save them there:
```
Fountain-Macro-Assistant/
├── screenshots/
│   ├── screenshot-1-popup.png
│   ├── screenshot-2-modal.png
│   └── ...
```
