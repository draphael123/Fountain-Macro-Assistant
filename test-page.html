Fountain - Macro Assistant - Test Page

How to Test:

  1. Make sure you have created at least one macro (e.g., .paula → This is a test)
  2. Type your shortcut in the input below (e.g., .paula)
  3. Press Space or Enter
  4. It should expand automatically!

Tip: Open the browser console (F12) to see debug messages.

Expected Behavior:

  • Type .paula + Space → Should expand to "This is a test"
  • Type .dr + Space → Should expand to "Daniel Raphael"
  • Type DR + Space → Should expand to "Daniel Raphael, Partner Manager"
