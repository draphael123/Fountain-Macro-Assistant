Privacy Policy for Fountain - Macro Assistant

Last Updated: December 2024

Summary: Fountain - Macro Assistant stores all data locally in your browser. We do not collect, transmit, or store any personal data on external servers. Your privacy is our priority.

Introduction

Fountain - Macro Assistant ("we", "our", or "the extension") is committed to protecting your privacy. This Privacy Policy explains how we handle information when you use our Chrome extension.

Data Collection

We do not collect, transmit, or store any personal data on external servers.

Local Storage Only

Fountain - Macro Assistant stores all data locally in your browser using Chrome's built-in sync storage:

  • Macros: Your text shortcuts and expansions are stored locally
  • Settings: Extension preferences are stored locally
  • Usage Statistics: Macro usage counts are stored locally

Chrome Sync Storage

If you have Chrome sync enabled, your macros and settings may be synced across your devices through Google's Chrome sync service. This is handled entirely by Chrome's built-in sync functionality, not by our extension.

Data Transmission

We do not transmit any data to external servers.

  • No analytics data is collected
  • No usage data is sent to third parties
  • No personal information is shared
  • No tracking or monitoring occurs

Permissions

Fountain - Macro Assistant requires the following permissions:

Storage Permission

  • Purpose: To store your macros and settings locally
  • Data: Only your macros and extension settings
  • Storage: Local browser storage only

ActiveTab Permission

  • Purpose: To enable text expansion on web pages
  • Usage: Only when you interact with text input fields
  • Data: No data is collected from web pages

Host Permissions (<all_urls>)

  • Purpose: To enable text expansion functionality on any website
  • Usage: The extension needs access to all URLs to work on any website where you type
  • Data: No data is collected from websites
  • Note: This permission is essential for the core functionality of the extension

Clipboard Read Permission (Optional)

  • Purpose: To support the {clipboard} variable feature
  • Usage: Only when you use macros containing {clipboard}
  • Data: Only reads clipboard when explicitly used in a macro
  • Note: This permission is requested only when needed

Third-Party Services

Fountain - Macro Assistant does not use any third-party services, analytics tools, or external APIs.

Data Security

  • All data is stored locally in your browser
  • Data is encrypted by Chrome's sync storage (if sync is enabled)
  • No external servers are involved
  • No data transmission occurs

Your Rights

You have complete control over your data:

  • Access: View all your macros through the extension popup
  • Export: Export your macros as JSON at any time
  • Delete: Delete individual macros or all data through the extension
  • Uninstall: Removing the extension deletes all local data

Children's Privacy

Fountain - Macro Assistant does not knowingly collect information from children. The extension is intended for general use.

Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with an updated "Last Updated" date.

Contact

  • Chrome Web Store listing (leave a review or contact developer)
  • GitHub repository (if applicable)

Compliance

This extension complies with:

  • Chrome Web Store Developer Program Policies
  • Chrome Extension Privacy Requirements
  • General data protection best practices
