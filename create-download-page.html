Installation Instructions

  1. Download all files (or the complete folder)
  2. Create a folder named fountain-macro-assistant-extension
  3. Place all files in that folder
  4. Create an icons subfolder and place icon files there
  5. Open Chrome → chrome://extensions/
  6. Enable Developer mode
  7. Click "Load unpacked"
  8. Select the folder you created
