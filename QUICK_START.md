# Quick Start Guide

Get your Fountain - Macro Assistant Chrome extension up and running in 5 minutes!

## Step 1: Create Icons (2 minutes)

You have two options:

### Option A: Use the Icon Generator
1. Open `create-icons.html` in your browser
2. Click "Download All Icons"
3. Move the downloaded files to the `icons/` folder:
   - `icon16.png`
   - `icon48.png`
   - `icon128.png`

### Option B: Create Your Own
1. Create three PNG images:
   - 16x16 pixels → `icons/icon16.png`
   - 48x48 pixels → `icons/icon48.png`
   - 128x128 pixels → `icons/icon128.png`
2. See `ICONS_INSTRUCTIONS.md` for detailed instructions

## Step 2: Load Extension in Chrome (1 minute)

1. Open Chrome
2. Go to `chrome://extensions/`
3. Enable **"Developer mode"** (toggle in top right)
4. Click **"Load unpacked"**
5. Select the folder: `C:\Users\danie\OneDrive\Desktop\Cursor Projects\Textexpander App`
6. Done! The extension should appear in your extensions list

## Step 3: Pin the Extension (30 seconds)

1. Click the puzzle piece icon (🧩) in Chrome's toolbar
2. Find "Fountain - Macro Assistant"
3. Click the pin icon (📌) to keep it visible

## Step 4: Test It! (1 minute)

1. Click the Fountain - Macro Assistant icon
2. Click "+ Add Macro"
3. Create a test macro:
   - Shortcut: `/test`
   - Expansion: `This is a test expansion!`
4. Click "Save"
5. Go to any website with a text field (like Google search)
6. Type `/test` and press Space
7. Watch it expand! 🎉

## You're Ready!

Your extension is now working. You can:
- Create more macros
- Access settings via right-click → Options
- Export/import macros for backup

## Troubleshooting

**Extension not showing?**
- Make sure Developer mode is enabled
- Check that all files are in the correct folder
- Ensure icons folder exists with all three icon files

**Macros not expanding?**
- Make sure you're typing in an editable field
- Press Space or Enter after typing the shortcut
- Check that the macro was saved correctly

**Need help?**
- Check the full `README.md` for detailed information
- Review the code comments in the JavaScript files
