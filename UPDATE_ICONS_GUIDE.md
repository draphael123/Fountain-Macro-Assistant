# Update Extension Icons - Fountain Logo

## Quick Steps

1. **Open the icon generator:**
   - Open `create-fountain-icons.html` in your browser
   - Or use the existing logo/icon files if you have them

2. **Generate icons:**
   - Click "Generate Icons" to preview
   - Click "Download All Icons" to save
   - You'll get: `icon16.png`, `icon48.png`, `icon128.png`

3. **Replace icon files:**
   - Copy the downloaded icons to:
     - `icons/icon16.png`
     - `icons/icon48.png`
     - `icons/icon128.png`
   - Also copy to `vercel-landing/extension/icons/`

4. **Alternative: Use existing logo**
   - If you have the Fountain logo as an image file
   - Use an online tool to resize to 16x16, 48x48, 128x128
   - Or I can help create a better version

## Icon Requirements

- **Format:** PNG with transparent background
- **Sizes:** 16x16, 48x48, 128x128 pixels
- **Colors:** Dark blue (#0044CC) and light blue (#00B8FF)
- **Design:** Fountain logo (stylized upward curves)

## After Updating Icons

1. Icons will be included in the extension ZIP
2. Icons will appear in:
   - Browser toolbar
   - Extension popup
   - Chrome Web Store listing
   - Extension management page

## Need Help?

If the generated icons don't match perfectly, provide:
