Extension Load Troubleshooting Guide

Step 1: Verify Folder Location

Your extension folder should be at:

C:\Users\danie\OneDrive\Desktop\Cursor Projects\Fountain-Macro-Assistant\fountain-macro-assistant-extension

Action: Open File Explorer and navigate to this path. You should see manifest.json directly in that folder.

Step 2: Open Chrome Extensions

  1. Open Google Chrome
  2. Type in address bar: chrome://extensions/
  3. Press Enter

Step 3: Enable Developer Mode

  1. Look at the top-right corner of the extensions page
  2. Find the toggle switch: "Developer mode"
  3. Turn it ON (should highlight/change color)
  4. After enabling, you should see new buttons appear

⚠️ Important: If you don't see "Load unpacked" button, Developer mode is not enabled!

Step 4: Load the Extension

  1. Click the "Load unpacked" button
  2. A file picker window opens
  3. Navigate to: C:\Users\danie\OneDrive\Desktop\Cursor Projects\Fountain-Macro-Assistant\fountain-macro-assistant-extension
  4. Click ONCE on the folder to select it (don't double-click into it)
  5. Click "Select Folder" button (bottom right)

❌ Common Mistake: Don't select manifest.json or any file. Select the FOLDER itself!

Step 5: Check What Happens

If Extension Appears:

  • ✅ Success! Extension is loaded
  • Look for "Fountain - Macro Assistant" in the list
  • Click the puzzle piece icon (🧩) in Chrome toolbar to find it
  • Pin it to your toolbar for easy access

If Extension Doesn't Appear:

  • Look for red error messages on the page
  • Scroll through the extensions list
  • Click any "Errors" button you see
  • Copy the exact error message

If File Picker Closes Immediately:

  • You might have selected a file instead of folder
  • Make sure you click the folder, not files inside it
  • Try again, being careful to select the folder

Quick Verification Checklist

Before loading, verify:

  • ✅ Folder exists at the correct path
  • ✅ manifest.json is in the folder root
  • ✅ icons/ folder exists with PNG files
  • ✅ Developer mode is enabled in Chrome
  • ✅ You're selecting the FOLDER, not a file
