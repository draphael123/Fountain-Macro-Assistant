v3.0.0 Latest Major Release January 2026

✨ New Features

  • Regex pattern matching with capture groups - use /pattern:regex/
  • JavaScript snippets - execute code with {js:code}
  • Auto-incrementing counters with {counter:name}
  • Random selection from options with {random:a|b|c}
  • Cloud sync across devices with free account
  • Keyboard shortcuts (Ctrl+Shift+M to open, Ctrl+Shift+N for quick create)
  • Auto-suggest popup while typing
  • Favorites system for quick access
  • Usage analytics dashboard
  • Pre-built macro packages (Customer Service, Marketing, Developer, etc.)
  • Shared macros library - browse and import community macros

🔧 Improvements

  • Completely redesigned popup UI with modern look
  • Dark mode support
  • Better performance and faster expansion
  • Improved undo functionality (last 10 expansions)
  • Enhanced input prompts with better UX
