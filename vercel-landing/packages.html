Get started instantly with pre-built macro collections. Download, import, and start typing faster.

How to Import Packages

1

Download a Package

Click the "Download" button on any package card above. The file will be saved as a .json file to your downloads folder.

2

Open Fountain Extension

Click the Fountain icon in your Chrome toolbar to open the extension popup. You can also use the keyboard shortcut Alt+Shift+F.

3

Access Import

In the extension popup, click the "••• More" button in the header, then select "Import" from the dropdown menu.

4

Select the Package File

In the Import modal, click "Choose File" or "Import from File" and navigate to your downloaded .json package file. Select it and click "Open".

5

Confirm Import

Review the macros to be imported and click "Import". Your new macros are now ready to use! Test them by typing any shortcut followed by Space or Tab.

💡 Tips

✏️

Customize After Import

Many packages include placeholder text (like "Your Name" or "your.email@example.com"). After importing, edit these macros to personalize them with your actual information.

📁

Organize with Folders

Imported macros are added to your main list. Consider creating folders (e.g., "Email", "Code", "Support") to organize them for easy access.

🔄

Merge or Replace

When importing, existing macros with the same shortcuts will be merged or you'll be prompted. Your existing macros are safe!
