📖 User Guide

🚀 Getting Started

Welcome to Fountain! Create text shortcuts that expand into longer snippets.

Quick Start

  1. Click "✨ New" to create a macro
  2. Enter a shortcut (e.g., /email)
  3. Enter the expansion text
  4. Type your shortcut + Space anywhere!

Keyboard Shortcuts

  • Ctrl+Shift+M - Open Fountain
  • Ctrl+Shift+N - Quick create
  • Ctrl+Z - Undo expansion

🔤 Variables

Date & Time

{date}Current date
{time}Current time
{date:YYYY-MM-DD}Custom format
{datetime}Date and time

Special

{cursor}Place cursor here after expansion
{input:Label}Prompt for input
{clipboard}Paste clipboard content
{counter:name}Auto-incrementing counter
{random:a|b|c}Random selection
{macro:/other}Nest another macro

Example:

Invoice #{counter:invoice}
Date: {date:YYYY-MM-DD}
Client: {input:Client Name}
{cursor}

⚡ Advanced Features

Conditional Expansions

Different text based on time or day:

Morning (0-12): "Good morning!"
Afternoon (12-18): "Good afternoon!"
Evening (18-24): "Good evening!"

Domain Filtering

Restrict macros to specific websites:

  • Email signatures only on Gmail
  • Code snippets only on GitHub

Typewriter Effect

Enable animated typing for expansions in settings.

🎯 Regex Patterns

Use regular expressions for dynamic triggers:

Pattern: /issue-(\d+)

Expansion: https://github.com/org/repo/issues/$1

Type: /issue-123

Result: https://github.com/org/repo/issues/123

Capture Groups

  • $1 - First capture group
  • $2 - Second capture group
  • $& - Entire match

💻 JavaScript Snippets

Execute JavaScript in your expansions:

Example:

{js:new Date().toLocaleDateString('en-US', {weekday: 'long'})}
// Output: "Thursday"

{js:Math.floor(Math.random() * 100)}
// Output: Random number 0-99

Available Context

  • Date, Math, String
  • encodeURIComponent()
  • JSON.stringify()

⚠️ JavaScript runs in a sandboxed environment for security.

💡 Pro Tips

Naming Shortcuts

  • Start with / or . to avoid conflicts
  • Keep them short but memorable
  • Use consistent prefixes (/email, /sig)

Organization

  • Use folders for categories (Work, Personal)
  • Star frequently used macros
  • Add tags for easy filtering

Power User

  • Combine variables: {input:Name} on {date}
  • Nest macros for complex templates
  • Use regex for dynamic patterns
