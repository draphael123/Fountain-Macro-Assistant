ℹ️ About

v3.0.0

Macro-Assistant helps you type faster with smart text expansion.

Features in v3.0:

  • 🎯 Regex pattern matching
  • 💻 JavaScript snippets {js:code}
  • 🔢 Auto-incrementing counters {counter:name}
  • 🎲 Random selection {random:a|b|c}
  • 📅 Date formatting {date:YYYY-MM-DD}
  • 🔗 Nested macros {macro:/other}
  • 💬 Auto-suggest popup
  • ⭐ Favorites system
  • 📊 Usage heatmap
  • 🎨 Colorful new UI
