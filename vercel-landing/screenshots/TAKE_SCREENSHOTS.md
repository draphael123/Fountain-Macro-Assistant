# How to Take Screenshots for the Website

This guide will help you take the 4 required screenshots for the "See It In Action" section.

## Required Screenshots

1. **usage-1-popup.png** - Extension popup showing macros
2. **usage-2-creating-macro.png** - Add/Edit macro modal
3. **usage-3-text-expansion.png** - Text expansion in action
4. **usage-4-settings.png** - Settings/Options page

## Quick Steps

### Screenshot 1: Extension Popup

1. **Load the extension in Chrome:**
   - Go to `chrome://extensions/`
   - Enable Developer mode
   - Click "Load unpacked"
   - Select your extension folder

2. **Open the popup:**
   - Click the extension icon in Chrome toolbar
   - Create 3-5 example macros if you don't have any:
     - `/email` → `your.email@example.com`
     - `/phone` → `(555) 123-4567`
     - `/sig` → `Best regards, Your Name`
     - `/date` → `Today is {date}`

3. **Take screenshot:**
   - **Windows:** Press `Windows + Shift + S` (Snipping Tool)
   - **Mac:** Press `Cmd + Shift + 4`
   - Select the popup area
   - Save as `usage-1-popup.png` in the `screenshots/` folder

**Tips:**
- Make sure the popup shows several macros
- Include the search bar and "+ Add Macro" button
- Crop to show just the popup (remove browser chrome)

---

### Screenshot 2: Creating Macro Modal

1. **Open the extension popup**
2. **Click "+ Add Macro" button**
3. **Fill in example data:**
   - Shortcut: `/email`
   - Expansion: `your.email@example.com`
   - Optionally show an alias or folder selection

4. **Take screenshot:**
   - Capture the modal (not the whole page)
   - Save as `usage-2-creating-macro.png`

**Tips:**
- Show the form fields clearly
- Include the modal title "Add Macro"
- Make sure text is readable

---

### Screenshot 3: Text Expansion in Action

1. **Open a text field:**
   - Go to Google Docs, Gmail compose, or any text input
   - Or use the demo on the website itself

2. **Type a shortcut:**
   - Type `/email ` (with a space)
   - Watch it expand

3. **Take screenshot:**
   - Show the expanded text
   - Or show before/after side by side
   - Save as `usage-3-text-expansion.png`

**Tips:**
- Use a clean, simple background
- Make the text clearly visible
- Show the expansion result

---

### Screenshot 4: Settings Page

1. **Open settings:**
   - Right-click extension icon → "Options"
   - Or go to `chrome://extensions/` → Find extension → Click "Details" → "Extension options"

2. **Show the settings page:**
   - Make sure export/import buttons are visible
   - Show any settings options

3. **Take screenshot:**
   - Capture the full settings page
   - Save as `usage-4-settings.png`

**Tips:**
- Include the page title
- Show export/import functionality
- Make it look organized

---

## Screenshot Requirements

- **Format:** PNG or JPEG
- **Size:** At least 1280x800 pixels (recommended)
- **Aspect Ratio:** 16:10 or 16:9
- **Quality:** High resolution, clear text

## Tools for Taking Screenshots

### Windows:
- **Snipping Tool:** `Windows + Shift + S`
- **Print Screen:** `PrtScn` key
- **Greenshot:** Free screenshot tool (recommended)

### Mac:
- **Screenshot:** `Cmd + Shift + 4`
- **Grab:** Built-in app

### Browser Extensions:
- **Awesome Screenshot**
- **Nimbus Screenshot**
- **Lightshot**

## After Taking Screenshots

1. **Save files:**
   - Save all 4 screenshots in the `screenshots/` folder
   - Use exact filenames:
     - `usage-1-popup.png`
     - `usage-2-creating-macro.png`
     - `usage-3-text-expansion.png`
     - `usage-4-settings.png`

2. **Optimize (optional):**
   - Resize if needed (1280x800px recommended)
   - Compress if file size is too large
   - Use tools like TinyPNG or ImageOptim

3. **Test:**
   - Open `index.html` in browser
   - Check that screenshots appear correctly
   - Verify they look good on the website
