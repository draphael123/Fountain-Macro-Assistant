## Screenshot Guidelines

### Size Recommendations
- **Installation screenshots**: 1280x800px or larger (16:10 aspect ratio)
- **Usage screenshots**: 1280x800px or larger
- **Format**: PNG or JPEG
- **File size**: Optimize to under 500KB each if possible

### Taking Screenshots

#### Installation Screenshots:
1. Use Windows Snipping Tool, Mac Screenshot, or browser extension
2. Capture full browser window for context
3. Highlight important UI elements if needed
4. Ensure text is readable

#### Usage Screenshots:
1. Show the extension popup clearly
2. Demonstrate key features
3. Use real examples (can blur sensitive data)
4. Show before/after for text expansion

### Adding Screenshots

1. Take screenshots following the guidelines above
2. Name them exactly as listed (case-sensitive)
3. Place them in this `screenshots/` directory
4. Commit and push to GitHub
5. The landing page will automatically display them

## Placeholder Behavior

If screenshots are missing, the landing page will show placeholder boxes with instructions. Once you add the actual screenshots, they will automatically appear.
