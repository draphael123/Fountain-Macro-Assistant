How to Import Macros

Learn how to import macros from files, shared library, or backups. Follow these simple steps to get started.

📁

Import from JSON File

Import macros from a previously exported JSON file. Perfect for backups or transferring macros between devices.

1 Right-click the Fountain extension icon in your Chrome toolbar and select "Options"
2 Scroll down to the "Data Management" section
3 Click the "Import Macros" button
4 Select your JSON file from your computer
5 Macros will be imported automatically! Duplicate shortcuts will be skipped.
💡 Pro Tip: Export your current macros first as a backup before importing new ones.
🌐

Import Shared Macros

Browse and import macros shared by other users from our community library.

1 Visit the Shared Macros Library
2 Browse or search for macros you want to import
3 Click "Import Macros" on any shared macro card
4 Return to extension Options (right-click icon → Options)
5 Click "Import Shared Macros" button in the Data Management section
💡 Alternative: Use a 6-character share code in the "Import by Code" tab on the Shared Macros page.
☁️

Import from Cloud Backup

Restore your macros from a cloud backup if you've synced them to your account.

1 Open extension Options (right-click icon → Options)
2 Log in to your account in the "Cloud Sync" section
3 Click "Restore from Cloud" button
4 Confirm the restore (this will replace your current macros)
5 Reload the extension popup to see your restored macros
⚠️ Note: This restores your own backed-up macros from your account. Make sure you've backed up your macros first!

JSON File Format

Your JSON file should contain an array of macro objects. Here's an example:

[
  {
    "id": "1",
    "shortcut": "/email",
    "expansion": "your.email@example.com"
  },
  {
    "id": "2",
    "shortcut": "/sig",
    "expansion": "Best regards,\nYour Name"
  }
]

Required fields: id, shortcut, expansion

Optional fields: aliases, tags, caseSensitive, folderId, conditions

Troubleshooting

Q: Import button not working?

Make sure you're using a valid JSON file. Check the file format in a text editor.

Q: "No valid macros found" error?

Ensure your JSON file is valid and contains an array of objects with id, shortcut, and expansion fields.

Q: Macros not appearing after import?

If you have duplicate shortcuts, the import succeeded but duplicates were skipped. Check the import confirmation message.

How the Macro Generator Works

Fountain's macro generator allows you to create intelligent text shortcuts that expand automatically. Here's how it works:

⌨️

1. Type Your Shortcut

Type your shortcut anywhere you can type text (email, documents, forms, etc.). Shortcuts typically start with a forward slash like /email or /sig.

⚡

2. Trigger Expansion

Press Space, Enter, or any punctuation mark (., ,, !, ?) to trigger the expansion. The extension detects your shortcut and replaces it instantly.

✨

3. Text Expands Automatically

Your shortcut is instantly replaced with the full expansion text you defined. The expansion happens seamlessly without interrupting your typing flow.

↩️

4. Undo if Needed

If you expand by mistake, press Ctrl+Z (or Cmd+Z on Mac) to undo the expansion. The extension tracks your last 10 expansions for easy undo.

💡 Pro Tips for Using the Generator:

  • Use descriptive shortcuts: Make shortcuts memorable (e.g., /email for your email, /phone for your phone number)
  • Start with a slash: Using / at the start helps avoid accidental expansions
  • Test your macros: Try your shortcuts in the interactive demo above before using them in real documents
  • Use variables: Add dynamic content with variables like {date}, {time}, or {clipboard}
  • Create aliases: Add multiple shortcuts for the same expansion (e.g., /email, /e, /mail all expand to the same email)
  • Organize with folders: Group related macros into folders for better organization

Frequently Asked Questions

How does Fountain - Macro Assistant work?

+

Fountain - Macro Assistant monitors text input fields on web pages. When you type a shortcut (like /email) followed by Space or Enter, it automatically replaces the shortcut with your predefined expansion text. All processing happens locally in your browser.

Is my data private and secure?

+

Yes! All your macros are stored locally in your browser using Chrome's secure sync storage. We don't collect, transmit, or store any personal data on external servers. Your data stays completely private and is only synced across your devices if you have Chrome sync enabled.

Does it work outside of Chrome?

+

Fountain - Macro Assistant is a Chrome extension and works within the Chrome browser on all websites. Chrome extensions cannot work in other desktop applications outside of the browser due to browser security restrictions.

Can I import macros from other text expanders?

+

Currently, Fountain supports importing macros from JSON format. If you have macros from other tools, you may need to convert them to our JSON format. We're working on adding direct import support for popular text expanders.

What happens if I uninstall the extension?

+

If you uninstall the extension, your macros are stored in Chrome's sync storage. If you reinstall the extension and are signed into the same Google account with Chrome sync enabled, your macros should restore automatically. However, we recommend exporting your macros as a backup before uninstalling.

Is there a limit on expansion length?

+

There's no hard limit on the length of expansions. However, very long expansions (several thousand characters) may take longer to process. For best performance, we recommend keeping expansions under 10,000 characters.

Can I use special characters in shortcuts?

+

Yes! You can use letters, numbers, and most special characters in shortcuts. However, shortcuts should start with a letter or special character (like / or !). We recommend using a prefix like / to avoid accidentally triggering expansions in normal typing.

Can I use multiple shortcuts for the same expansion?

+

Yes! This is called "aliases". When creating or editing a macro, you can add aliases in the "Aliases" field (comma-separated). For example, if your shortcut is /email, you can add aliases like /e, /mail and all three will trigger the same expansion.

What are conditional expansions?

+

Conditional expansions allow you to have different text based on time, day, or context. For example, you can have a greeting macro that says "Good morning!" in the morning, "Good afternoon!" in the afternoon, and "Good evening!" in the evening. You can also set different expansions for weekdays vs weekends.

How do I backup my macros?

+

You can export your macros at any time from the Settings page (right-click the extension icon → Options). Click "Export Macros" to download a JSON file with all your macros. You can import this file later to restore your macros or share them with another device.

Can I undo an expansion?

+

Yes! After an expansion, you'll see an undo notification. You can click "Undo" or simply press Ctrl+Z (or Cmd+Z on Mac) to revert the expansion. The extension keeps track of the last 10 expansions for undo.

Why does the extension need access to all websites?

+

The extension needs access to all URLs (<all_urls> permission) to enable text expansion functionality on any website where you type. This is essential for the core functionality - without it, the extension would only work on specific websites. The extension only reads text input fields and does not collect or transmit any data.

How many macros can I create?

+

There's no hard limit! You can create as many macros as you need. Chrome's sync storage has a limit of about 100KB per item, but with typical macro sizes, you can easily have hundreds or even thousands of macros.

Does it sync across devices?

+

Yes! If you have Chrome sync enabled, your macros will automatically sync across all your devices where you're signed in with the same Google account. This is handled by Chrome's built-in sync functionality.
