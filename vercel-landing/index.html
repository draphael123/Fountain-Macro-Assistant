User Guide

Getting Started

1

Install the Extension

Download and install Fountain - Macro Assistant from the Chrome Web Store or manually load it as an unpacked extension.

2

Create Your First Macro

Click the extension icon, then click "+ Add Macro". Enter a shortcut (e.g., /email) and the expansion text (e.g., your.email@example.com).

3

Start Typing

Go to any website, type your shortcut, and press Space or Enter. Watch it automatically expand!

Creating Macros

Basic Macro

Shortcut: /email

Expansion: your.email@example.com

With Variables

Shortcut: /sig

Expansion: Best regards,{newline}John Doe{newline}Sent on {date} at {time}

With Aliases

Shortcut: /email

Aliases: /e, /mail

Expansion: your.email@example.com

All three shortcuts work: /email, /e, /mail

Available Variables

{date} Current date
{time} Current time
{datetime} Date and time
{year} Current year
{month} Month (01-12)
{day} Day of month
{clipboard} Paste clipboard
{newline} Line break
{tab} Tab character

Frequently Asked Questions

How does Fountain - Macro Assistant work?

+

Fountain - Macro Assistant monitors text input fields on web pages. When you type a shortcut (like /email) followed by Space or Enter, it automatically replaces the shortcut with your predefined expansion text. All processing happens locally in your browser.

Is my data private and secure?

+

Yes! All your macros are stored locally in your browser using Chrome's secure sync storage. We don't collect, transmit, or store any personal data on external servers. Your data stays completely private and is only synced across your devices if you have Chrome sync enabled.

Does it work outside of Chrome?

+

Fountain - Macro Assistant is a Chrome extension and works within the Chrome browser on all websites. Chrome extensions cannot work in other desktop applications outside of the browser due to browser security restrictions.

Can I use multiple shortcuts for the same expansion?

+

Yes! This is called "aliases". When creating or editing a macro, you can add aliases in the "Aliases" field (comma-separated). For example, if your shortcut is /email, you can add aliases like /e, /mail and all three will trigger the same expansion.

What are conditional expansions?

+

Conditional expansions allow you to have different text based on time, day, or context. For example, you can have a greeting macro that says "Good morning!" in the morning, "Good afternoon!" in the afternoon, and "Good evening!" in the evening. You can also set different expansions for weekdays vs weekends.

How do I backup my macros?

+

You can export your macros at any time from the Settings page (right-click the extension icon → Options). Click "Export Macros" to download a JSON file with all your macros. You can import this file later to restore your macros or share them with another device.

Can I undo an expansion?

+

Yes! After an expansion, you'll see an undo notification. You can click "Undo" or simply press Ctrl+Z (or Cmd+Z on Mac) to revert the expansion. The extension keeps track of the last 10 expansions for undo.

Why does the extension need access to all websites?

+

The extension needs access to all URLs (<all_urls> permission) to enable text expansion functionality on any website where you type. This is essential for the core functionality - without it, the extension would only work on specific websites. The extension only reads text input fields and does not collect or transmit any data.

How many macros can I create?

+

There's no hard limit! You can create as many macros as you need. Chrome's sync storage has a limit of about 100KB per item, but with typical macro sizes, you can easily have hundreds or even thousands of macros.

Does it sync across devices?

+

Yes! If you have Chrome sync enabled, your macros will automatically sync across all your devices where you're signed in with the same Google account. This is handled by Chrome's built-in sync functionality.
