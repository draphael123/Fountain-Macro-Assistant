📸 Screenshot Helper

Follow these steps to capture screenshots for the "See It In Action" section

1 Extension Popup Screenshot

  1. Open Chrome and make sure the extension is loaded
  2. Click the extension icon in the toolbar to open the popup
  3. Create some example macros if you don't have any:
    • /email → your.email@example.com
    • /phone → (555) 123-4567
    • /sig → Best regards, Your Name
  4. Take screenshot:
    • Windows: Press Windows + Shift + S
    • Mac: Press Cmd + Shift + 4
  5. Select only the popup area (crop out browser chrome)
Save as: usage-1-popup.png
💡 Tip: Make sure the popup shows the search bar, macro list, and "+ Add Macro" button clearly.

2 Creating Macro Modal Screenshot

  1. Open the extension popup
  2. Click the "+ Add Macro" button
  3. Fill in example data:
    • Shortcut: /email
    • Expansion: your.email@example.com
    • Optionally add an alias or select a folder
  4. Take screenshot of the modal (not the whole page)
Save as: usage-2-creating-macro.png
💡 Tip: Make sure all form fields are visible and text is readable. Include the modal title "Add Macro".

3 Text Expansion Screenshot

  1. Open a text field: Go to Google Docs, Gmail compose, or any website with text input
  2. Type a shortcut: Type /email (with a space)
  3. Watch it expand to the full text
  4. Take screenshot showing the expanded text
Save as: usage-3-text-expansion.png
💡 Tip: Use a clean background. You can show before/after or just the final expanded text.

4 Settings Page Screenshot

  1. Open settings:
    • Right-click extension icon → "Options", OR
    • Go to chrome://extensions/ → Find extension → "Details" → "Extension options"
  2. Show the settings page with export/import buttons visible
  3. Take screenshot of the full settings page
Save as: usage-4-settings.png
💡 Tip: Include the page title and make sure export/import functionality is visible.
