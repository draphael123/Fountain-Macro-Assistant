# Fountain - Macro Assistant Landing Page

This is the landing page for the Fountain - Macro Assistant Chrome Extension, hosted on Vercel.

## Deployment

This site is configured for Vercel deployment. To deploy:

1. **Using Vercel CLI:**
   ```bash
   npm i -g vercel
   vercel
   ```

2. **Using GitHub Integration:**
   - Connect your GitHub repository to Vercel
   - Vercel will automatically deploy on push

3. **Using Vercel Dashboard:**
   - Go to https://vercel.com
   - Click "New Project"
   - Import this directory
   - Deploy

## Custom Domain

To use a custom domain (e.g., fountain.net):

1. Go to your Vercel project settings
2. Navigate to "Domains"
3. Add your custom domain
4. Follow DNS configuration instructions
