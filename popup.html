📖 Fountain - Macro Assistant - User Guide

🚀 Getting Started

Welcome to Fountain - Macro Assistant! This extension helps you type faster by creating text shortcuts that automatically expand into longer snippets.

Quick Start (3 Steps):

  1. Create a Macro: Click "+ Add Macro" button
  2. Set Shortcut: Enter a shortcut (e.g., /email)
  3. Set Expansion: Enter the text to insert (e.g., your.email@example.com)

How to Use:

  1. Go to any website with a text input field
  2. Type your shortcut (e.g., /email)
  3. Press Space or Enter
  4. Watch it expand automatically! ✨

📝 Basic Usage

Creating Macros

  1. Click the "+ Add Macro" button
  2. Enter a Shortcut - this is what you'll type
  3. Enter an Expansion - this is what will be inserted
  4. Optionally assign to a Folder for organization
  5. Click "Save"

Editing Macros

Click on any macro in the list to edit it. You can change the shortcut, expansion, folder, or delete it.

Organizing with Folders

  1. Click the 📁 button to create a folder
  2. When creating/editing a macro, select a folder from the dropdown
  3. Use the folder filter to view macros by folder

Searching Macros

Use the search box to quickly find macros by shortcut or expansion text. Combine with folder filter for precise results.

✨ Key Features

🔤 Macro Variables

Use dynamic variables in your expansions:

  • {date} - Current date
  • {time} - Current time
  • {datetime} - Date and time
  • {clipboard} - Paste clipboard content
  • {newline} - Line break
  • {tab} - Tab character

Example: Meeting on {date} at {time}

↩️ Undo Functionality

  • After expansion, an undo notification appears
  • Click "Undo" or press Ctrl+Z to revert
  • Works for the last 10 expansions

📊 Usage Statistics

  • See how many times each macro has been used
  • View "Last used" date
  • Sort by usage to find your most valuable macros

🔍 Enhanced Search

  • Search by shortcut or expansion
  • Sort by: Name, Usage, Recent, Created
  • Filter by folder

⌨️ Keyboard Shortcuts

  • Ctrl/Cmd + N - New macro
  • Ctrl/Cmd + F - Focus search
  • Ctrl/Cmd + / - Show shortcuts
  • Escape - Close modal
  • Ctrl/Cmd + Z - Undo expansion

🔤 Macro Variables

Variables make your macros dynamic and powerful. Use them in your expansion text.

Date & Time Variables

{date}Current date (e.g., "12/29/2024")
{time}Current time (e.g., "3:45:30 PM")
{datetime}Date and time together
{year}Current year (e.g., "2024")
{month}Month (01-12)
{day}Day of month (01-31)
{hour}Hour (00-23)
{minute}Minute (00-59)
{second}Second (00-59)
{timestamp}Unix timestamp

Other Variables

{clipboard}Paste clipboard content
{newline}Insert a line break
{tab}Insert a tab character

Example Usage

Shortcut: /signature

Expansion:

Best regards,
John Doe
Sent on {date} at {time}

Result:

Best regards,
John Doe
Sent on 12/29/2024 at 3:45:30 PM

🔗 Macro Aliases

Aliases allow multiple shortcuts to trigger the same expansion.

How to Add Aliases

  1. Create or edit a macro
  2. In the "Aliases" field, enter comma-separated shortcuts
  3. Example: /e, /mail, /email
  4. Save the macro

Example

Shortcut: /email

Aliases: /e, /mail

Expansion: your.email@example.com

Result: All three work!

  • Type /email + Space → expands
  • Type /e + Space → expands
  • Type /mail + Space → expands

Visual Indicator

Macros with aliases show a 🔗 icon next to the shortcut. Hover to see all aliases.

⚡ Conditional Expansions

Conditional expansions let you have different text based on time, day, or context.

How to Set Up

  1. Create or edit a macro
  2. Check "Enable conditional expansion"
  3. Set conditions:
    • Time Range: Hours when macro should work (0-23)
    • Weekdays Only: Only expand Mon-Fri
  4. Add conditional expansions for specific scenarios

Example: Time-Based Greeting

Shortcut: /greeting

Default: Hello!

Conditional 1:

  • Time: 0-12 (morning)
  • Expansion: Good morning!

Conditional 2:

  • Time: 12-18 (afternoon)
  • Expansion: Good afternoon!

Conditional 3:

  • Time: 18-24 (evening)
  • Expansion: Good evening!

Example: Weekday vs Weekend

Shortcut: /status

Default: Available

Conditional 1:

  • Weekdays only: ✓
  • Expansion: In the office

Conditional 2:

  • Weekdays only: ✗ (weekends)
  • Expansion: Out of office

Visual Indicator

Macros with conditions show a ⚡ icon next to the shortcut.

💡 Tips & Best Practices

Shortcut Naming

  • Use descriptive shortcuts (e.g., /email not /e1)
  • Start with a special character (e.g., / or .) to avoid conflicts
  • Keep shortcuts short but memorable
  • Be consistent with naming patterns

Organization

  • Use folders to group related macros
  • Name folders clearly (Work, Personal, Email, etc.)
  • Review and clean up unused macros regularly
  • Sort by usage to find your most valuable macros

Variables

  • Combine multiple variables for powerful expansions
  • Use {newline} for multi-line text
  • Test variables to see how they format
  • Use {clipboard} to paste copied content

Performance

  • Keep macro count reasonable (100-200 is fine)
  • Use folders to organize large collections
  • Search is fast even with many macros
  • Export regularly as backup

Common Use Cases

  • Email addresses: /email → your full email
  • Phone numbers: /phone → your phone number
  • Signatures: /sig → email signature with variables
  • Common phrases: /ty → "Thank you!"
  • Code snippets: /func → function template
  • Addresses: /addr → your full address

Troubleshooting

  • Macro not expanding? Make sure you press Space or Enter after the shortcut
  • Wrong expansion? Check for similar shortcuts that might conflict
  • Variables not working? Check spelling and use curly braces {}
  • Can't find a macro? Use search or check folder filter
