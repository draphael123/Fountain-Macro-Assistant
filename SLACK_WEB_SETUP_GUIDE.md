# Using Fountain Extension with Slack - Setup Guide

## ✅ Solution: Use Slack Web (Recommended)

Your Fountain extension works perfectly with **Slack Web**! Here's how to set it up for the best experience.

## Step 1: Access Slack Web

1. Go to **https://slack.com**
2. Click **"Sign in"** or **"Open Slack"**
3. Sign in with your workspace credentials
4. You're now using Slack Web! ✨

## Step 2: Install Slack Web as Desktop App (Optional)

Make Slack Web feel like the desktop app:

### Chrome/Edge:
1. Go to **https://slack.com**
2. Click the **install icon** in the address bar (looks like a monitor/plus icon)
3. Click **"Install"**
4. Slack opens in its own window (looks like desktop app!)
5. **Extension still works perfectly!** ✅

### Firefox:
1. Go to **https://slack.com**
2. Click the **three dots menu** (⋮)
3. Select **"Use Slack as App"**
4. Follow the prompts
5. Extension works! ✅

## Step 3: Use Your Macros in Slack

1. **Open any Slack channel or DM**
2. **Click in the message input field**
3. **Type your macro shortcut** (e.g., `/email`)
4. **Press Space or Enter**
5. **Watch it expand!** 🎉

### Example:
- Type: `/email`
- Press: Space
- Result: `your.email@example.com`

## Keyboard Shortcuts Still Work

All Slack keyboard shortcuts work in web version:
- `/` - Commands
- `Ctrl+K` - Quick switcher
- `Ctrl+Shift+M` - All DMs
- And more!

## Tips

1. **Bookmark it:** Save slack.com to bookmarks bar
2. **Pin the tab:** Keep Slack always open
3. **Use multiple workspaces:** Switch easily
4. **Desktop shortcut:** Create shortcut to Slack Web
5. **Startup:** Set browser to open Slack on startup

## Troubleshooting

**Extension not working?**
- Make sure you're on slack.com (not desktop app)
- Check extension is enabled in browser
- Try refreshing the page
- Check browser console for errors

**Slack feels slow?**
- Clear browser cache
- Disable other extensions
- Check internet connection
- Try different browser

## Alternative: System-Wide Text Expansion

If you really need it to work in desktop apps, consider a system-wide tool:
- **Windows:** AutoHotkey, Espanso, PhraseExpress
- **Mac:** TextExpander, aText, Espanso

*Note: These require separate installation and setup*
